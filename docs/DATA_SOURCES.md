# مستندات منابع داده و مجوزهای استفاده (BazaarLens-IR Data Sources)

| ویژگی | توضیحات |
| :--- | :--- |
| **نام دیتاست اصلی** | BaSalam (comments & products) / `RadeAI/BaSalam_comments_products` |
| **لینک مستقیم منبع اول** | [Hugging Face Dataset Card](https://huggingface.co/datasets/RadeAI/BaSalam_comments_products) |
| **لینک مستقیم منبع دوم** | [Kaggle Dataset Page](https://www.kaggle.com/datasets/radeai/basalam-comments-and-products) |
| **مجوز استفاده (License)** | **MIT License** (ثبت‌شده در متادیتای مخزن Hugging Face) |
| **حجم و فرمت فایل اصلی** | ۴۳۵ مگابایت، شامل دو فایل CSV (`BaSalam.products.csv` و `BaSalam.reviews.csv`) |
| **واحد پولی ستون‌های قیمت** | **ریال ایران (IRR)** در دیتاست خام؛ در پایپلاین به **تومان (Toman)** تقسیم بر ۱۰ تبدیل می‌شود |
| **ملاحظات حریم خصوصی** | در جدول نظرات (`reviews.csv`)، ستون‌های `name_of_user` و `photo_of_user` باید پیش از انتشار عمومی حذف یا ناشناس‌سازی شوند |
| **منبع جایگزین معتبر** | [Digikala Products Metadata (117K) - Kaggle](https://www.kaggle.com/datasets/mohammadaminorojloo/digikala-products-product-metadata-117k) |
